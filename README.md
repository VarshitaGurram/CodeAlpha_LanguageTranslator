# 🌐 LinguaFlow — Language Translation Tool
### CodeAlpha Internship | Task 1

A sleek AI-powered language translation web app built with **Streamlit** and **Google Translate API** (via `deep-translator`).

---

## ✨ Features
- Translate text between **29 languages** including Indian regional languages
- **Text-to-Speech** — hear the translation spoken aloud
- **Copy** translated text instantly
- Clean, modern dark UI

---

## 🚀 How to Run

### 1. Install dependencies
```bash
pip install -r requirements.txt
```

### 2. Run the app
```bash
streamlit run app.py
```

The app will open at `http://localhost:8501`

---

## 🛠 Tech Stack
| Tool | Purpose |
|------|---------|
| Python | Core language |
| Streamlit | Web UI |
| deep-translator | Google Translate API wrapper |
| gTTS | Text-to-Speech |
